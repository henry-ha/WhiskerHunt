# Hush Hunt v3.10.20 · Build 83

Use the **Android MAUI source ZIP** for Visual Studio. Extract into a new folder, open `WhiskerHunt/WhiskerHunt.csproj`, Clean, Rebuild, and deploy over the current installation. **Do not uninstall** the previous app if you want to preserve saved wildlife.

### Theme verification on your phone
- Home screen and theme picker should display v3.10.20/build 83.
- Open Settings > Home screen themes; choose Static, then a theme such as Twilight Fox.
- The Home hero must show one uninterrupted wildlife background, without the old two horizontal photo-blur extensions.
- Switch to another theme and verify both the Home image and main action cards update.
- Dynamic should cycle through the same twenty v83 scenes when the app restarts.

### Fidelity note
`themes_v83` are 2160 × 3840 **upscaled full-screen compositions from smaller original illustrations**, not native-detail 4K renders. They remove the old blur bands but true 4K source-art remasters are still outstanding.
