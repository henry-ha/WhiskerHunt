# Hush Hunt v3.10.21 — Build 84

**Source code release, not a compiled APK.**

## Install
1. Extract the Android MAUI ZIP into a clean, new folder.
2. Open `WhiskerHunt.csproj` in Visual Studio with the .NET MAUI Android workload.
3. Clean, rebuild and deploy over your existing Hush Hunt app.
4. **Do not uninstall** — local discovery photos and collection records are stored in app data.

## Confirm on your OnePlus 11
- Open Home: both Live Capture and AR Safari should fit above the bottom navigation without a long scroll.
- Open Collection: animal-family filters appear, followed quickly by saved photo tiles; tap 'More challenges & virtual wildlife' for bingo and other extras.
- Open Live Capture and press `0.6×`: select **Open 0.6× phone camera**, choose the wide lens in the phone camera, take a photo. The app should return directly to animal identification.

Note: Genuine ultrawide **live preview in the WebView** remains unavailable unless the camera is exposed through Android WebRTC APIs; v3.10.21 does not claim to solve that underlying platform limitation.
