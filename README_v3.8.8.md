# Hush Hunt v3.8.8 (Android build 52)

Open `WhiskerHunt.sln` in Visual Studio with the .NET MAUI Android workload. Build using your existing Android phone target. This is the native **source project**, not an APK; the experimental native ARCore code still requires compatible Android binding dependencies and a real supported device.

**Before deploying:** export a full collection backup. Build **over the existing app without uninstalling**. Keep the original application ID `uk.whiskerhunt.mobile`; changing it risks losing access to the existing private app storage.

New: wildlife-aware name/story suggestions; rolling burst during the live capture gesture; top five shots; Collection navigation/capture wording. The game still requires real-world sightings through live camera and does not offer gallery or video upload as a path to new catches.

More detail: `HushHunt_v3.8.8_CHANGELOG.md` and `HushHunt_v3.8.8_TEST_RESULTS.md`.
