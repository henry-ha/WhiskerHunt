# Hush Hunt v3.10.2

This update focuses on the wildlife field guide.

## What's new
- New realistic field-guide asset pack: `field_art_v65`
- Offline species/type illustrations refreshed across the app
- Browser preview and MAUI resources updated to the new pack

## Main files changed
- `BrowserPreview/app.js`
- `WhiskerHunt/Resources/Raw/app.js`
- `BrowserPreview/field_art_v65/*`
- `WhiskerHunt/Resources/Raw/field_art_v65/*`

## Intent
The guide now aims to be more educational and closer to real-life appearance so little explorers can more easily recognise what they have found.
