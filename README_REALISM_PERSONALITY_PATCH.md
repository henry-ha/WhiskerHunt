Important limitation:
This patch improves presentation and interactivity, but it does not replace the bundled deer / labrador / squirrel GLB meshes.
If those assets still have missing eyes, disconnected paws, or missing legs, the actual 3D model files themselves must be replaced with higher-quality GLBs.
