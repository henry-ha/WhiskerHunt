# Hush Hunt v3.10.10 source release

Includes the updated Android MAUI solution and browser demo. For Android, open `WhiskerHunt.sln`, rebuild and deploy **over** the old installation. Do not uninstall: local collection records can be lost.

The camera zoom buttons should always show 1×, 2×, 3×, with 0.6× shown only if WebView exposes a wide-angle lens/track. Pinch inward to zoom out and spread two fingers apart to zoom in. Actual camera hardware and the Android app could not be compiled/tested in this environment; this is source only.
