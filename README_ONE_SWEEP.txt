HUSH HUNT - ALL 61 WILDLIFE ASSET SLOTS - ONE SWEEP
===================================================

WHY THIS IS NOT AN AUTOMATIC 61-ANIMAL PHOTOREALISTIC PACK
--------------------------------------------------------
Your original 61 GLBs are substantially from 3DAssets.dev's AI-generated
packs. Fetching another 61 models from the SAME catalogue doesn't improve
realism. There is no verified open-access collection of 61 appropriate,
professionally realistic, correctly licensed GLBs with matching species,
coat colours and animated skeletons. Pretending otherwise would replace
bad animals with other bad ones.

WHAT THIS DOES RIGHT NOW
------------------------
- Scans ALL 61 current GLB slots in ONE run.
- Downloads 11 independently sourced, higher-detail candidates where an
  independently checked 1DesignTool download is available.
- Includes the 61-slot species/licence catalogue.
- Stages additional GLBs dropped into USER_LICENSED_GLBS with exactly the
  correct filenames (see WILDLIFE_61_SLOTS.json).
- Validates GLB structure, bundled textures, size, animation presence,
  triangle budgets, and checks current-file SHA256 where possible.
- Creates FULL_61_SWEEP_RESULTS.csv and OPEN_61_MODEL_REVIEW.html for all
  61 slots in the same execution. Each unresolved slot gets research links.
- Preserves ALL ORIGINAL FILES until quality approval, with SHA256-checked
  timestamped backups for accepted replacements.
- One batch installer installs every approved file across all 61 slots.

ONE-SWEEP COMMAND
-----------------
Extract into E:\inetpub\wwwroot\WhiskerHunt, preserving relative paths.
Double-click RUN_ALL_61_ONE_SWEEP.cmd. A one-page 61-species report opens.
Put acquired, app-licensed GLBs into USER_LICENSED_GLBS with the EXACT
animal target names, then rerun the same one-sweep script.

TO INSTALL BATCH
----------------
For each review-approved source, view the GLB from all sides in Blender,
confirm that it is the right species, eyes and paws exist, fur cutouts
look correct, and it has no attached trees/logs/ground props.
Read Wildlife_Review_Queue/<model>/review.json and set "approved": true
only for actually approved files. Models with exact_species_match:false
are not installed by batch installer. Double-click
INSTALL_ALL_APPROVED_IN_ONE_PASS.cmd to install all approved with backups.

IMPORTANT LIMITS
----------------
11 direct downloads are alternative research candidates, NOT verified
improvements until manually previewed on your machine. All are STATIC;
WALK cannot animate legs without separate rigs/animations. Some include
props, alpha fur or inappropriate subspecies. 61 checks != 61 replacements.
Missing candidates are explicitly reported; no fake 'success'.
The downloads cannot be tested from this offline build environment.
Do not uninstall the app; project backups and on-device saved collection
are different, and Android rebuilds have not been tested here.

LICENSING
---------
1DesignTool permits embedding in games/apps but restricts raw model-pack
redistribution. Files download only on your own PC, not bundled here.
Sketchfab/Fab/CGTrader have individual licences, authentication, or
purchase requirements; their model binaries cannot be fetched blindly.
Confirm you hold rights to any asset you place in USER_LICENSED_GLBS.

VERSION: One-sweep research/ingest tool, not an APK or full 61 GLB pack.
