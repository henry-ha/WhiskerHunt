# Hush Hunt 3.10.1 source project

Open `WhiskerHunt.sln` in Visual Studio with the .NET 10 Android/MAUI workload. Restore NuGet packages, build, and deploy **over** the app with the existing ID `uk.whiskerhunt.mobile` (do not uninstall, clear storage, or change package ID).

Home now has Live Capture and AR Safari shortcuts. In live view, tap **Quick photo** or keep using the capture tools. Lens zoom buttons are available only when Android exposes the hardware capability.

Browser demo: open `BrowserPreview/index.html` in a secure origin (localhost or HTTPS) to access live camera. The browser may expose different camera lenses than the OnePlus Android WebView.

Keep an exported backup before a major app upgrade. No data migration or collection reset is included.
