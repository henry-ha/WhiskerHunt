# Hush Hunt v3.9.0 (Android .NET MAUI)

1. Back up the existing Collection from the installed app.
2. Extract the **complete** ZIP into a new folder and open `WhiskerHunt.sln` in Visual Studio with the .NET 10 Android workload installed.
3. Restore NuGet packages, then **Clean Solution → Rebuild Solution**. Deploy to the installed app without uninstalling.
4. On the OnePlus, open Hush Hunt v3.9.0 · build 54, then AR Safari. ARCore / Real surfaces is now tappable; follow on-screen camera / Google Play Services for AR prompts. If the app displays an ARCore error, capture the full message.
5. Go to live wildlife capture → select Dog, Cat, Snail, Dragonfly, Butterfly and other categories to see their new subtype artwork.

Android package ID: `uk.whiskerhunt.mobile` (unchanged).
Native collection filename: `whisker-hunt-state.json` (unchanged).

Notes: 128 illustrated varieties are family-specific game art, **not expert species-ID reference photos**. The ARCore Activity supports plane hit-testing/anchors, with flat creature artwork. Actual ARCore launch/tracking still requires a device test.
