# Hush Hunt v3.10.12 — Build 75

This release fixes the duplicated Home menu buttons and adds dynamic wildlife imagery to the two main Home launch tiles.

## How to install
1. Extract Android package into a clean new folder.
2. Open `WhiskerHunt.sln` in Visual Studio.
3. Clean/Rebuild, then deploy over the existing installation. Do not uninstall unless you have backed up your local collection.
4. Confirm Home shows v3.10.12 / Build 75.

When Dynamic is on, new wallpaper and both button backgrounds rotate at app launch. Static in Settings locks them to the chosen set.

Android camera/ARCore behavior is unchanged from v3.10.11.
