# Hush Hunt v3.10.19 / build 82 — Majestic Home Themes

The **20 approved nature-scene compositions are actually integrated** into the Android MAUI WebView app and browser demo. Both load `index_v82.html`, `app_v82.js` and `style_v82.css`.

- 20 individually bundled wildlife wallpapers in `themes_v82`
- 20 theme-picker previews in `theme_previews_v82`
- 40 themed Live Capture / AR Safari card images in `button_scenes_v82`
- Static selection immediately changes the Home scene and persists, Dynamic rotates on reopening the app
- No duplicate Collection / Map / Rewards launch buttons; standard bottom nav remains
- All original database/storage identifiers and existing collection logic are preserved

### Artwork quality disclosure
These backgrounds use the **individual landscapes from the approved 20-scene gallery**, feathered into portrait compositions. The image files are exported at 1200x2048; the source gallery artwork is lower resolution, so this is **not native 4K-detail artwork**. The scenery and subjects match the approved gallery; do not mistake the earlier resampled old cutouts for these new scenes.

### Installation
Extract the Android ZIP to a new folder; open `WhiskerHunt.csproj`, clean/rebuild, deploy over the existing app without uninstalling it to preserve saved discoveries. No APK is included.
