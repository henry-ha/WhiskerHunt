# Hush Hunt v3.9.4 — Build 58

1. Back up your in-app Collection first.
2. Extract this project to a new directory and open `WhiskerHunt.sln` with Visual Studio.
3. Choose the existing Android build target, Clean and Rebuild Solution, and deploy onto the installed Hush Hunt app **without uninstalling**.
4. Test real wildlife capture, species cards, ARCore Safari (Place → Collect), Collection and Map.
5. Android home icon: this source has explicit branded mipmap resources. If your old *shortcut* remains cached, remove just the shortcut from your home screen and drag a new one from the app drawer. Don't clear Hush Hunt storage.

The source contains original, illustrative wildlife art. It is not a trained recognition engine or official identification guide. Native ARCore photo capture is experimental and requires testing on your phone.
