# Hush Hunt v3.9.8 — Build 61

## Install
1. Make a backup using Hush Hunt's Collection export.
2. Extract the complete ZIP and open `WhiskerHunt.sln` in Visual Studio.
3. Clean Solution, then Rebuild Solution.
4. Deploy **over** the installed Hush Hunt app. **Do not uninstall or clear app storage.**
5. Check the in-app version stamp: `Hush Hunt v3.9.8 · build 61`.
6. Go to a wildlife variety picker to check the updated pictures.

The updated images have their own new `field_art_v61` paths so WebView can't accidentally reuse the previous asset URLs.
