Hush Hunt AR crash logger v2 (Windows)

1. Extract ALL files in this ZIP together to a writable folder (e.g. your WhiskerHunt solution directory or Desktop). Do not run the files from inside the ZIP.
2. Double-click OPEN_HUSH_HUNT_LOGGER.cmd (recommended) or CAPTURE_AR_CRASH_LOG.bat.
3. Leave the console open. It will print the ADB path and show your connected OnePlus device.
4. It captures existing logs first. Press Enter to start a new recording.
5. Reproduce 3D Safari > Domestic Shorthair crash on the phone, then press Enter in the console.
6. Find HushHunt_AR_Log_Filtered.txt in the same folder as the files (or Desktop/temp if the folder was read-only).
7. Review any logs for personal/private information before sharing.

If no log appears, open HushHunt_Logger_Status.txt. The script always creates status/filtered output in its chosen writable location.
If the console closes unexpectedly, launch OPEN_HUSH_HUNT_LOGGER.cmd, which keeps Command Prompt open.

This diagnostic does not change app data, source code, APKs, or GLB models.
